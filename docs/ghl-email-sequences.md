### Env vars required in Vercel

| Variable | Description |
|----------|-------------|
| `GHL_WEBHOOK_URL` | GoHighLevel workflow webhook URL. Receives POST from both `/api/ghl-capture` and `/api/webhooks/stripe`. GHL identifies the contact type from the `source` or `productId` field in the payload and routes to the correct sequence. |

**Payload from `/api/ghl-capture`:**
```json
{ "email": "user@example.com", "source": "audit", "timestamp": "..." }
```

**Payload from `/api/webhooks/stripe`:**
```json
{ "email": "user@example.com", "productId": "full-access", "sessionId": "cs_..." }
```
